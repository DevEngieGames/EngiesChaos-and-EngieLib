<summary>Mod compatibility.</summary>
  
  - **This mod can run without [AttributeFix](https://modrinth.com/mod/attributefix) but please do install it for any version, the mod works much better with it installed. If you are playing with AttributeFix installed it is recommended to set "generic.max_health"'s "value" number to the 32 bit integer limit which is 2,147,483,647/2147483647 or something lower of value as anything above this can break certain mobs and make them unkillable on certain built in difficulties.**

  - **[Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap) & [Worldmap](https://modrinth.com/mod/xaeros-world-map) mod support is built in for this mod.**

  - **It is *heavily* recommended to play with any mod that allows you to have a custom stack size over 127 like [Bigger Stacks](https://modrinth.com/mod/biggerstacks).**

![The mod adds the following:](https://cdn.modrinth.com/data/cached_images/b7f7b3d44b14afe760fe4fdae2fbf4ea21989963.png)

- **Structures.**
    - **The structures are named the following:**
    - Item House, Item House XXL, Sharko House, Dimension House, Throwback House, Antimatter House.
- **Advancements.**
    - Most are related to obtaining a specific item. Others are for eastereggs or are for a 100% maybe a 101% as well.
- **Armor and tools.**
    - The tools can range from being tiny to extremely massive!
    - Mini, Regular, Big, Large, Huge, Enormous, Gigantic, Massive, Biblically, Monstrosity, Doomsday, Super Doomsday, The End, Engies, Mindscape Engie's, EngieGames.
    - There is Antimatter & Dark Matter variants of all of these. Except for Mindscape Engie's.
- **Mobs.**
    - Ranging from passive and helpful to extremely aggressive!
    - They also drop items for you to craft tools!
- **Recipe books!**
    - Will most likely be updated between updates.
    - You can go into the config (Default: O) and click the left arrow to find the button for Volume 1.
- **Sharkos.**
    - Ranging from the standard Blue and White to a very rare Gray!
    - Sharko, Albino, Rare, Epic, Legendary, Mythic, Exotic, Engie, Rare Engie, Tiger.
- **A whole lot of items.**
    - "Go be a collector!"
    - There's a BUNCH of items that I([EngieGames](https://modrinth.com/user/EngieGames)) physically cannot name every single one here. xd
- **Lore mode.**
    - Latest versions have this disabled as it is getting a rework soon.
- **Doomsday**
    - Survive what Engie's Chaos has to throw at you.
    - Some versions run on old code so the code has a chance to break which an operator can run "/EngiesChaos doomsday summon" twice to fix it. These versions also cause damage to the world so it is recommended to backup your worlds. This does not apply for versions before the Doomsday rework.
- **Challenge.**
    *   Good luck.
    *   Enable the insanity gamerule to get access to this!
- **Throwback.**
    *   Take a view of how 2023 All About Engie was!
    *   Only 10 hearts(20 HP). Old mob looks, Tools.
